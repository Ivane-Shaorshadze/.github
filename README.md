# .github

- `CONTRIBUTING.md` — მონაწილეობის წესები
- `CODE_OF_CONDUCT.md` — ქცევის კოდექსი
- `SECURITY.md` — უსაფრთხოების პოლიტიკა
- `SUPPORT.md` — დახმარება
- `PULL_REQUEST_TEMPLATE.md` — PR შაბლონი
- `ISSUE_TEMPLATE/` — issue შაბლონები
- `profile/README.md` — პროფილის გვერდი
